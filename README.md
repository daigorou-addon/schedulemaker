# ScheduleMaker（スケジュール表メーカー）

週間・月間のスケジュール表を、SNSに載せやすい画像として作れるWebツールです。インストール不要、ブラウザだけで使えます。

**公開ページ:** https://daigorou-addon.github.io/schedulemaker/

## できること

- **週間／月間** の2モード
  - 週間: 1日3件まで（時刻・内容・メモ・カテゴリ）
  - 月間: 1日2件まで（カレンダーに表示）
- **レイアウトタイプ**
  - 週間: グリッド / サイドバー / リスト / ボード / タイムライン
  - 月間: カレンダー / ビッグ数字 / リスト / タイムライン / カレンダー＋リスト
- **カラー10種** ＋ カスタム（背景・文字・セル・強調を自由に指定、背景透過にも対応）
- **画像サイズ** を選べます: 自動 / 9:16（TikTok・リール）/ 1:1（Instagram）/ 16:9（YouTube・X）
- **サンプル** から始められます（配信者・学生・社会人・推し活など、週間4種・月間6種）
- キャラ画像（任意）、フッター文、お休み日の設定
- 「来週分にする（+7日）」「翌月分にする」ボタンで、同じ内容のまま次の期間へ
- 週の始まりを月曜／日曜から選択
- **PNGで保存**。データはJSONで保存・読み込みでき、ブラウザにも自動保存されます
- ライト／ダーク表示の切り替え
- スマホ対応（縦・横画面）

## 対応言語

日本語 / English / 한국어 / 简体中文 / 繁體中文 / Español

画面の文言に加えて、画像内の曜日・月名・「お休み」なども選んだ言語で表示されます。サンプルの中身は日本語以外では英語になります。

## プライバシー

すべての処理はこの端末内で行われます。入力した内容や画像は、どこにも送信されません。

## 使い方

1. 表示モード（週間／月間）とタイプ、カラーを選ぶ
2. 必要ならサンプルを選んで、中身を入れ替える
3. タイトル・名前・各日の予定を入力する
4. 「PNGで保存」で画像をダウンロードする
